# EMC for Spectrum

Play [Spectrum](https://modrinth.com/mod/spectrum) with [ProjectE](https://modrinth.com/mod/projecte) and its gems and ores have no EMC value. This data-only add-on adds foundational EMC coverage.

- **Hand-tuned EMC** for Spectrum's gemstones (Topaz / Citrine / Onyx / Moonstone shards) and mined resources (Raw Azurite, Raw Malachite, Shimmerstone, Paltaeria, Stratine, Neolith, Shattered Bedrock, Quitoxic Powder).
- Items crafted from these through the mod's vanilla-style recipes **derive their EMC automatically**.

It adds no items, blocks, or recipes — only EMC data. Values apply on world load; open a Transmutation Table to see them.

**Foundational coverage only.** Spectrum is a very large mod whose machine recipes (Pedestal, Fusion Shrine, Spirit Instiller, …) aren't auto-derivable by ProjectE, so deep machine-only content has no EMC in this first version — the gemstones, ores, and their direct craftables do. Stateful gear and trinkets carry no EMC by design.

**Dependencies**

- [ProjectE](https://modrinth.com/mod/projecte) — required
- [Spectrum](https://modrinth.com/mod/spectrum) — required
- NeoForge 1.21.1

EMC values are a considered first pass; balance and coverage feedback is welcome on the issue tracker.
