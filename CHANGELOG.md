# Changelog

## v0.1.0

Initial release — foundational coverage.

- ProjectE EMC integration for Spectrum (NeoForge 1.21.1).
- Hand-set EMC for Spectrum's foundational resources: gemstone shards (topaz/citrine/onyx/moonstone), raw azurite/malachite, shimmerstone, paltaeria/stratine fragments, neolith, shattered bedrock, quitoxic powder.
- Vanilla-recipe craftables derive EMC from these.
- Spectrum's custom machine recipes are not auto-derivable by ProjectE, so deep machine-only content is not covered in this first pass.
- Stateful gear / trinkets intentionally left without EMC.
- Data-only: adds no items, blocks or recipes.
